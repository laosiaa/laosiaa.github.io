DSH Go 安卓端：从入门到精通

在电脑上把 DeepSeek Harness 用顺手之后，下一个需求几乎必然是「在外面也想让它干活」。DSH Go 就是干这个的：一个安卓 App，既能在手机本机跑一套完整的 DSH 引擎，也能当你电脑上那套 DSH 的遥控器。

三个前提先说清楚，免得看完才发现方向不对：

  1. 它是社区项目，不是 DeepSeek 官方。基于开源的 DeepSeek Harness 构建，AGPL-3.0 授权，和 DeepSeek 没有任何隶属关系；
  2. 只在安卓上发布。iOS 版还在开发和真机测试，没有公开安装包（要自己用 Mac 签名编译），鸿蒙版在推进中；
  3. 手机上跑的是”引擎”，模型还是要联网。DSH Go 本机运行 ≠ 模型离线，请求照旧发给你配置的模型提供方，按你的账号计费。

一、先搞懂它有两种身份

打开 App 第一次就要选，而且后面随时能切：

身份 谁在干活 适合谁 代价
本机引擎 DSH 跑在手机里（内置 Ubuntu 环境） 手机性能还行、想随时随地用 占约 1 GB 空间，内存吃紧的手机容易卡
远程主机 DSH 还在电脑/服务器上，手机只是遥控 手机内存小、或工作区文件都在电脑上 电脑得开着，并且能被手机连上

官方建议很直白：手机内存或存储不够就选远程。反过来，如果你的电脑不常开，那本机引擎才是唯一选择。

一条容易被忽略的：只连远程主机时，不需要在手机上装运行环境——这一下就省了 1 GB。

二、安装：三个坑写在最前面

要求：Android 8.0（API 26）及以上。

包怎么选：

包 用在哪
arm64 绝大多数 64 位安卓手机（默认下这个）
x64 x86_64 设备与模拟器，藏在发布说明末尾的「其他版本下载」里
32 位 ARM 不提供

下载走 GitHub Releases 或官网 go.dshtui.com/download，侧载安装要允许该来源。

三个必须先知道的坑：

  1. 装过签名不同的旧测试包，不能覆盖安装——必须先卸载，而卸载会清空对话、Linux 环境和设置；
  2. 本机引擎要预留约 1 GB（装 Ubuntu + Node + DSH 运行时）；
  3. 当前构建是 APK 侧载，不走 Google Play，所以系统可能反复提示”未知来源”。

三、本机引擎：装、更、重置

3.1 装运行环境

首次选「本机」时会引导安装；已经选了远程的，之后也能补：引擎页 → 安装运行环境，或在切换主机时点本机。装完自动启动。

默认用 PRoot 兼容启动（不需要 root，也不需要另装 Termux）。开发者选项里还有个「直接启动」，默认关闭——它能更快，但兼容性差，出问题要回退，别一上来就开。

Ubuntu 环境里 Python / git / rg 不是预装的。要装就在对话里直接说：

注意：安装软件属于系统写入，会单独请求批准——「工作区写入许可」不能代替它。

3.2 更新与重置（数据在这丢的）

  • 更新会先核对架构、Ubuntu 版本和 Python，再沿用原环境；无法确认兼容、更新清单损坏或旧进程没停，会停止并说明原因，不会自动清空重建。
  • 重置运行环境是修复”起不来”的最后手段。默认确认范围会删掉：对话、工作区、插件、设置（含自定义模型渠道），家目录 /root 下没保留的内容（含工作区文件、AGENTS.md、插件自己存的数据，比如记忆）都会一起没。App 里保存的 DeepSeek Key 会自动补回，其余不会。
  • 重置无法撤销，要留的对话先导出：对话里用 /export，或在「全部功能 → 导出对话日志」。
  • 只是暂时不用，别卸载环境，改成「停止引擎」+ 关掉「打开 App 时自动启动」。

四、连你自己的电脑：SSH 主机两种模式

远程主机页 → 添加 SSH 主机。前提：那台机器开着 SSH，并且装了 DSH（npm i -g @deepseek-ai/dsh）。

填主机、用户名、端口（默认 22），然后是最关键的一项——实例管理：

模式 它会做什么 什么时候用
托管启动（默认） 帮你启动/复用远端 DSH，启动命令默认 dsh web 让 App 全权管理那个实例
只连接 只建一条 SSH 隧道到远端 127.0.0.1:<端口>，不启动、不重启、不读写状态文件 远端已有自己管理的实例

只连接要额外填两样：远端 DSH 端口，以及该实例启动链接里的登录令牌。工作目录选填，只连接模式下必须写绝对路径。

几个实操细节：

  • 首次连接会弹**「信任这台主机？」，要去那台主机上核对指纹**，一致再点信任；
  • nvm 装的 DSH，启动命令填完整路径；
  • SSH 压缩默认开启（协商认证后压缩），服务器不支持就保持未压缩；
  • 令牌、SSH 密码、私钥只存在手机安全存储里；
  • 托管模式发现”还活着但启动命令不同、日志丢失”的实例时，会拒绝连接而不是替你杀掉它；确实要替换，才在编辑页点「重启托管 DSH」——这会中断其他客户端和进行中的对话。

五、DSHarness Remote：不给公网也能连

SSH 适合”我知道那台机器的 IP 和密码”的场景；出门在外、家里 NAT 后面，用 DSHarness Remote（另一个社区项目）更顺。

它的思路是：Harness 主机不开任何公网端口、不需要公网 IP，通过端到端加密的双向链路连接，优先 P2P，全球多 TURN 节点中转，极端情况用 Relay 兜底。

装法（桌面端）：

  1. DSH Desktop 的扩展 / 插件管理里，选从 npm 安装，填包名和版本；
  2. 装完重启 Desktop；
  3. DSH 0.2.2 起，插件页能检查版本并一键更新，热更新失败会尝试恢复旧版。

DSH 0.2.2 之前用 GitHub / 本地 link 方式装的，要切回 npm 才能在线更新。

双向都行：在手机端 DSH Go 里也装这个插件，电脑端和 Web 端就能反向连到手机上的 DSH——手机干活、电脑看结果。

代价也要说清楚：Remote 当前只支持图片附件，不能在 App 内打开网页版，插件管理只到开关级别，不支持 DS Bot 和对话日志导出。

六、手机操控：这是 DSH Go 最特别的能力

开启后，本机引擎可以读屏幕、点按、输入。这是”让 AI 真的用你的手机”，所以要一层层放开权限。

6.1 开启三步

  1. 确保走的是本机引擎（远程主机不行）；
  2. 「准备」里点无障碍服务 → 去开启，在系统无障碍设置里打开「DSH 手机操控」；侧载 App 打不开开关时，点「无障碍开关点不动？」，按品牌去开允许受限制的设置；
  3. 通知也要开——确认卡和「停止」按钮靠它。

6.2 授权与边界

  • 任务开始时在原生确认框里授权一次，最长 30 分钟（睡觉也计入），同一引擎+同一对话内的普通读屏、开应用、点按、滚动不再逐次弹窗；
  • 暂停、停止、断开或任务结束会撤销授权；新对话或过期要重新授权；
  • 密码、验证码、付款、系统设置默认交还给你，屏幕上会显示「需要你来操作」，你弄完点继续；
  • 熄屏、锁屏，或连续 3 分钟没有新操作，任务直接结束；
  • 三档确认随你选，敏感操作默认交还；放宽规则或开「解除限制」前先想清楚后果；
  • 不打扰模式（后台点屏幕）要求 Android 14+，且需要 Shizuku 或自连 ADB；
  • Android Shell 是另一项独立授权（默认关），跑的是手机的 sh 而不是 Ubuntu bash，每条命令都要原生确认，允许一次 / 本轮允许 / 取消，屏幕操作的免确认不适用。

一条安全铁律：别在存着支付或银行信息的设备上开「解除限制」。

七、日常手感：几个用了就回不去的细节

功能 说明
中途插话 回复生成中也能发消息，排队后随时「立即发送」
过程折叠 干活的过程收成一行，结果不被刷屏
原生 / 网页版一键切换 停在同一段对话，下次打开还是上次那个模式
分享卡 + 对话回放 回复一键做分享卡；整段对话生成链接，对方在浏览器回放，链接端到端加密、密钥只在链接里（拿到完整链接的人可以读并保存）
横屏 / 平板重排 侧栏常驻、内容居中，弹键盘不挤
主题与图标 6 套主题色（可跟随壁纸）、4 款桌面图标、3 种功能图标风格
桌宠 Deepy 和鲸娘：敲代码、空翻、举手等你确认；开「App 外显示」会跟到桌面
中英文 默认跟随系统，设置里可切

八、后台不被杀

安卓的省电策略是手机端 agent 的头号敌人。DSH Go 会检测到后台被杀后提醒你，并直接跳到对应的放行设置页——vivo、小米、华为、荣耀、OPPO 都有覆盖。

自己也要做两件事：把这台 App 加入电池「不限制」名单，以及别期待锁屏后还能长跑——手机操控任务本身就会因熄屏而结束。

九、排错表（按症状查）

症状 原因 处理
发不出消息 / 一直没回复 引擎没起、网络、或模型渠道配置 先看引擎页状态，再确认模型渠道可用
引擎反复启动失败 环境损坏 先看真实报错；确实损坏再「重置运行环境」（会清数据，先导出）
App 能对话，headless 却报 MISSING_CREDENTIAL headless profile 默认不读 App 里存的 Key/账号登录 给 DEEPSEEK_API_KEY 环境变量，或写进启动目录 .env / $DSH_HOME/.env
手机操控用不了 没开开关/引擎没起/连着远程主机/在安全模式/无障碍没开 页面顶部会写明还差哪一项，按提示逐项补
任务做一半停了 熄屏、锁屏，或 3 分钟无操作 保持屏幕常亮、别锁屏
悬浮条挡屏 位置不对 拖到左右或任意高度，或拖出屏幕边收成小球；开「闲置时自动收起」
宠物不见了 选了不显示 / 藏起 1 小时 / App 外显示没开 宠物页重新选一只、点「立即显示」，检查悬浮显示权限
插件装了但界面没有 没启用 / 需要重启引擎 / 远程主机缺 dsh-go 桥接 启用并重启；远程主机一般没有原生界面，去「全部功能」的插件分组或网页版入口开
App 闪退 可在设置里做自动故障分析 按提示导出信息再反馈

提醒一句：headless 和 App 里保存的凭据是两套东西。用 DeepSeek 账号登录拿到的令牌不能填进 DEEPSEEK_API_KEY。

十、隐私与安全（这段别跳过）

  • 模型请求会发给你配置的提供方；开启手机操控后，任务需要的屏幕文字可能被发送，支持看图的模型还可能收到截图；
  • 「发送匿名使用统计」默认开启，位置在 设置 → 隐私与分享 → 发送匿名使用统计，第一次引导里也能关；
  • 本机网页版只接受 App 自己的访问；分享链接虽然端到端加密，但拿到完整链接的人就能读内容，转发前看一眼预览；
  • 只连可信主机、只装可信插件；不要让 AI 无人值守地跑不可逆任务；
  • 这是社区项目，按”现状”提供、无担保——重要数据先备份。

十一、入门 / 熟练 / 精通

层级 会做什么
入门 装 APK、选本机或远程、配上模型、发第一条消息
熟练 本机环境装/更新/重置与导出；配 SSH 主机（托管 vs 只连接）；开手机操控并管好三档确认；处理后台被杀
精通 用 DSHarness Remote 打通家里 NAT 与外面；手机与电脑互为被控端；headless 单独配凭据；按排错表定位到具体环境（而不是一崩就重置）；在隐私与权限之间划清自己能接受的边界

一句话总结：DSH Go 把”agent 在电脑上”变成了”agent 在你手上”，能力上限不变，代价是权限、后台存活和网络这三件事都得你自己安排明白。

版本说明：本文依据 DSH Go 仓库（AGPL-3.0）与 DSHarness Remote 的官方说明整理，核对时间 2026-11-27；两个项目都在快速迭代（DSH Go 单日仍在提交），界面文案与路径可能变动，遇到不一致以 App 内当前页面为准。
