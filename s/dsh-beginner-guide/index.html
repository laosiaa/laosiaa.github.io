第 1 部分 · 理清概念

DSH 的全名是 DeepSeek Harness，直译是“马具”：底层模型是一匹力大无穷的野马，DSH 就是套在它身上的缰绳和鞍具，让 DeepSeek 拥有了可以控制你电脑的“身体”。

网页版 AI 和本地 DSH 的区别，就一句话：网页版碰不到你电脑里的任何文件，只能靠你主动上传；本地的 DSH （以及 Claude Code、Codex 这类工具）可以直接读你的文件、调动命令行，替你把事情做完。

Vibe Coding（AI 许愿机）：不需要懂编程，用大白话描述你想要什么，AI 就帮你实现。你只需要做 AI 最严厉的领导。

为什么推荐 DSH：

  • 价格：在主流模型里非常便宜，新账号还送 6 元鲸元券。
  • 门槛：相比 Claude Code 和 Codex，不需要特殊网络，也没有动不动封号的问题，是目前门槛最低、最稳定的选择。

一张图记住整个体系：DeepSeek 是大脑，DSH 是身体，后面要装的插件和环境就是它的手，最后呈现给我们的就是 Vibe Coding 工具。本期后面的美化、鲸鱼娘，就是给她穿上衣服、装上心。

第 2 部分 · 下载、安装与第一次对话

现在已经不用在终端里敲命令了，下载桌面版，双击安装就能用。

  1. 打开 DSH 官网，点 Download for Windows（苹果电脑选 Mac 版）。
  1. 选择安装位置，建议不要装在 C 盘，然后一直下一步，安装完桌面会生成图标，双击启动。
  1. 启动后点 登录，会跳到浏览器，用 DeepSeek 账号登录（没有就先注册），再选“打开 DeepSeek Harness”。
  2. 左下角头像 → 设置 → 账号与余额：新账号会送 6 元鲸元券，强度不高够用好多天；用完点“充值”自己选金额。
  3. 开始聊天前设置四件事：
    • 工作区：你的项目文件夹，它产生的所有内容都只存在这里。
    • 模型：选最新的 DeepSeek-V4.1-Flash 1017（聪明，而且是多模态）。
    • 思考强度：选“高”。
    • 修改权限：建议直接选 完全权限。只给“工作区内修改”的话，它安装东西时经常会失败。

输入框上方的四种模式

输入框上面点“标准模式”可以切换模式。日常使用选标准模式就够了。

模式 官方说明 什么时候用
标准模式 处理代码、文件和资料，适合大多数任务。Agent 会按需使用检索、编辑和终端等工具 日常大部分事情
PTC 模式 包含标准模式的所有能力，更适合批量调用工具，并对结果进行筛选、整理、去重、统计或汇总 一次处理一大批文件或数据
极简模式 Agent 使用终端和图片读取工具，并支持上下文压缩，适合测试和对比其基础表现 测试模型本身
创造模式 用对话定制 DSH：让 Agent 编写插件，添加新功能或界面；也能组合工具和提示词，创建自己的模式 有个想法，一句话让它做个插件

创造模式是官方 11 月 2 日专门发视频推的：比如输入“帮我做一个下班倒计时插件”，它会自己写完、装好，直接出现在界面里。官方给的 7 个提示词见文末附录。

  1. 设置完，发一句“你好”试试，收到回复就说明一切正常。恭喜你已经超过了 50% 的小伙伴。

第 4 部分 · 插件生态

把 DSH 想象成一台手机：插件就是手机里的各种 App，每个代表一个新功能；Skill 像快捷指令，把固定的几步流程一键跑完；MCP 像数据线和蓝牙，把它接到外部的各种工具上。

哪里找插件：社区的插件精选网站 awesome-dsh-plugin.com 收录了大量 DSH 插件。

先装插件市场 DSH Market，以后就能在软件里直接挑插件、一键安装：

  1. 打开 dsh-market 仓库，复制安装命令。
  1. 回到 DSH，新建一个对话，把命令粘贴进去，再说一句“帮我安装一下这个插件”。
  2. 等它装完。中间出现报错也不用管，它会自己把报错处理好。
  1. 装好后点左侧「插件」，会多出一个 插件市场 标签。筛选里选按 Star 排序，最受欢迎的会排在前面；分类里还有 UI、计费、主题外观等。

万能招：任何 GitHub 上的插件，都可以直接把仓库链接发给 DSH，说“帮我安装一下这个插件”。装插件前记得把权限调成完全权限。

第 5 部分 · 美化：鲸鱼娘动态壁纸 + 开机动画

动态壁纸

  1. 插件市场 → 主题与外观，选 Star 最高的 dsh-wallpaper-engine（仓库），点安装 → 确认安装。
  1. 装完界面会变成深色，但还没有壁纸：因为还没上传。点 设置 → 壁纸引擎。
  2. 往下滑，点「选择文件」，选好壁纸视频后点 OK，鲸鱼娘就出现了。

壁纸素材哪里来：

  • Steam 上的 Wallpaper Engine 创意工坊，素材多，很多是免费的。
  • 本期视频里的鲸鱼娘动态壁纸：鲸鱼娘动态壁纸.mp4（下载后发给 DSH：“帮我把这个视频设成动态壁纸”）。插件介绍见 dsh.plus 的 dsh-wallpaper-engine 页。
  • 自己做：先生成一张喜欢的鲸鱼娘图，再用万相、Seedance 2.5 这类 AI 视频模型写一句提示词生成动态视频。

开机动画

社区已经有很多开机动画，视频里用的是 dsh-boot-suite（作者演示视频：黑色大肥鱼启动，感谢各位作者）：

  1. 在 GitHub 仓库页点绿色的 Code，复制仓库地址。
  2. 回到 DSH 桌面端粘贴，说“帮我安装一下这个插件”。
  3. 装好后重启，就能看到完整的开机动画（约 29 秒，带音乐和英文播报）。

第 6 部分 · 手机端 DSH Go

DSH Go 是 B 站小伙伴做的 DSH 手机版：既能在手机上直接跑，也能遥控你电脑上的 DSH。目前只有安卓版。手机上不要给它太多权限，它真的能控制你的手机。

电脑端：装遥控插件

  1. 先把权限改成 完全权限。
  2. 下载 UP 主准备好的安装脚本 install-dsh-plugin.ps1，发给 DSH 说“帮我执行这个脚本”（也可以自己在 PowerShell 里运行 .\install-dsh-plugin.ps1，想先看看会装哪个版本就加 -DryRun）。脚本会自动找到和你 DSH 版本对应的插件版本再装。实际装的是 DSHarness Remote 插件，直接从 GitHub 装有时会因为版本不对应报错，所以做成了脚本。
  3. 装好后左侧会出现 Remote，点进去能看到远程工作台和一个二维码，电脑这边就好了。

手机端

  1. 手机打开 DSH Go 官网下载页（或 GitHub Releases）下载 APK 并安装，常见手机选 arm64 包。
  2. 首次启动选 本机，耐心等它装好运行环境；权限选项建议少给。
  3. 登录 DeepSeek 账号，再填入你的 API Key（本机对话目前需要 API Key）。
  4. 要互通电脑：选 连接主机 → 用 GitHub、知乎或谷歌登录（视频里知乎登不上，用的是谷歌）→ 扫电脑 Remote 页面上的二维码。
  5. 之后手机和电脑的对话完全同步，在手机上就能让电脑干活。

API Key 和二维码都等于你的账号密码，不要截图发给别人。

第 7 部分 · 鲸鱼娘：桌宠、QQ、语音、人格卡

这一章装的是 SurfCore：一个超级大合集，把 B 站、QQ、桌宠、语音这些最热门的功能合在了一起。流程比较长，耐心跟着做。

7.1 安装 SurfCore（鲸鱼娘出现）

  1. 下载 UP 主做好的「SurfCore 分享安装指南」：SurfCore-分享安装指南.md，把全文复制下来。
  2. 打开 DSH，新建会话，权限改成 完全权限。
  3. 把指南文件拖进对话框发送。它弹出选项时，自己输入：
  1. 安装中会问你几个问题：
    • 主人的 QQ 号：填 你自己 的 QQ，不要填鲸鱼娘的 QQ。
    • 放行哪些 QQ 群：按需填，不需要可以跳过。
    • QQ 网关：先跳过，后面 7.2 专门装。
    • 语音：本地免费，但音色差一点、感情少一点；云端（火山引擎）更自然。密钥可以选“先装好，密钥我自己填”，7.3 再填。
  2. 让它继续跑，装完鲸鱼娘就会出现在桌面右下角。

桌宠小技巧：右键她 → “穿什么呢”可以换衣服；如果她的脚显示不全，右键 → “调整大小…”拖一下“桌宠大小”滑块就正常了。

7.2 QQ 接入（一定用小号）

  1. 发给 DSH：“三件事情都帮我处理好：需要火山的密钥就帮我打开网页我去申请，插件也帮我安装好。”它会装好 SnowLuma（QQ 协议网关）并打开它的网页控制台。
  2. 控制台要“访问令牌”：令牌就是 DSH 回复里写的 WebUI 初始账号的初始密码，复制、粘贴、进入控制台。
  1. 勾选协议 → 同意并继续 → 设置一个新密码 → 保存并完成 → 用新密码重新登录。
  2. 左侧选 进程注入 → 加载 QQ → 登录 QQ，状态变成“已在线”。
  3. 记住：一定要用小号！千万不要拿自己的大号测试。 这是给鲸鱼娘用的账号。
  4. 登录完跟 DSH 说：“已经成功登录，后面的流程你帮我去处理。”它会把链路接通。
  5. 想让她进哪个群，截图告诉 DSH，它会全部设置好。测试：单聊发“你好”，群里 @ 她。

7.3 语音

设置 → SurfCore → 语音。本地语音包直接点安装（或让 DSH 帮你装，很快）。云端稍微麻烦一些：

  1. 打开 火山引擎语音控制台，切到 新版体验。
  2. 左侧 开通管理：建议全部开通，包括 声音复刻（点开通 → 勾选协议 → 开通模型）。
  1. 左侧 声音复刻 → 上传声音 → 同意 → 开始复刻 → 起个名（视频里叫“小W”）→ 确定。没有现成的声音？可以用这三个音色样本：爱丽丝（中配） · 芙宁娜 · 测试2（样本来自网络收集整理，仅供个人学习试用）。
  2. API Key 管理 → APP ID：页面上有三个值。先复制 APP ID，粘贴到 DSH 设置里的 AppID；再复制 Access Token，粘贴到 Access Key。
  3. 音色库 → 我的音色：复制刚生成的音色 ID，粘贴到 DSH 的音色 ID，点 保存。
  4. 回到语音页顶部，选 云端语音包 → 启动，等一会儿 → 测试连接，显示连接成功就好了。
  5. 右键鲸鱼娘 → 语音对话，就能听到她的声音。

APP ID、Access Token、音色 ID 都是你的密钥，录屏和截图时记得打码。

7.4 人格卡（去掉 AI 味）

  1. 打开「大肥鱼人设卡」网站，挑一张喜欢的，视频里选的是「傲2娇8·呆萌修订版」，点 复制提示词。
  1. 不要去设置里一个个框填，条条框框太多。直接发给 DSH：
  1. 写完后打开 设置 → SurfCore → 角色，可以看到人格核心、人格语气、场景人格都已经填好。
  1. 语音对话问她一句“你喜欢我嘛”，傲娇味就出来了。

课后作业与回顾

课后作业：B 站。SurfCore 里的 B 站功能视频里故意没有演示，用前面学的方法自己跑通：

  • 跟 AI 沟通：告诉 DSH 你想让鲸鱼娘在 B 站做什么
  • 连接起来：设置 → SurfCore → B站，用「扫码登录小肥鱼」登录
  • 设置好各种东西：称呼、昵称等。同样用小号

知识体系回顾：

部件 对应 本期章节
大脑 DeepSeek 大模型 第 1–2 部分
身体 DSH 桌面端：打通本地文件和自动化 第 2–3 部分

AI 进步很快，但核心是让工具真正为你所用：多拿 AI 解决工作和生活里那些枯燥繁琐的麻烦，把时间留给天马行空的想法。

C. 安全与隐私提醒

  • QQ、B 站都 用小号，不要用主力账号测试。
  • API Key、火山 APP ID / Access Token / 音色 ID、SnowLuma 密码、登录二维码，都不要截图外传。
  • 手机端只给必要的权限。
  • 「完全权限」会让它不再逐步确认，只在你信任的任务里使用。
  • DSH 还在开发者预览阶段，版本更新可能让旧插件失效，遇到问题先看对应仓库的 Issue。
