DSH Go 酒馆：从入门到精通

先把一个最常见的误会说清楚：DSH Go 的酒馆不是把 SillyTavern 的网页塞进手机跑，它是 App 里原生实现的一个角色扮演区——不装本机运行环境、不连远程主机，直接用你在设置里填的 DeepSeek API Key 调模型。

但它在数据格式上跟 SillyTavern 是打通的：角色卡（PNG / JSON / CHARX）、世界书、预设、正则、快速回复、ST 主题、.jsonl 聊天记录，都能导进来。所以你以前的卡和预设不会白攒。

三个前提：

  1. 角色卡、对话、设置全部只存在这台手机上，卸载/重置前必须备份；
  2. 酒馆不审查卡和模型的内容，卡里的 HTML 和脚本会在消息里跑——所以它给了两个安全开关（后文有）；
  3. 上下文越长每回合越贵，长对话要自己控制节奏。

一、进酒馆：三条路

方式 操作
切换模式 对话列表 › 切换模式 › 模式 › 酒馆，返回键回到工作
开机直进 酒馆首页 我的 → 启动时进入 设成酒馆
首次引导 第一次打开 App 时选 和角色聊天，会跳过安装直接进酒馆，并自动把「启动时进入」设好

第三条是新手最省事的：它跳过了 1 GB 的运行环境安装，因为酒馆根本不依赖本机引擎。

进去第一件事不是导卡，是填 Key：酒馆 › 我的 › 酒馆设置 › 模型与连接。这里和对话共用同一个 Key；没填时页面会提示去填写。

二、模型与连接：Flash 还是 V4 Pro

酒馆 ‹ 我的 › 酒馆设置 › 模型与连接

  • 主模型：Flash 与 V4 Pro 二选一。日常陪聊、大量短回合用 Flash；要它稳定守住人设、处理长设定和复杂状态时换 V4 Pro。
  • 思考：一个开关。开着更”想得深”，但每回合的耗时和 token 都会涨；纯角色扮演多数时候没必要开。
  • DeepSeek API Key：填一次，酒馆和对话共用。

生成 里还有默认预设的回复上限和温度——注意这句：自带预设的对话以它自己的为准，也就是说卡或预设里写了参数，全局默认就不生效了。

想按对话单独调，去 舞台 › 本局，那里列着这段对话正在用的模型、思考、人设、预设、世界书、排版和背景图。

三、导入：一个入口认所有文件

酒馆 › 导入

从文件导入会自动判别类型：角色卡（PNG / JSON / CHARX）、世界书、预设、正则、快速回复、SillyTavern 的聊天记录。一次可以选多个文件，会逐个提示结果；如果不是角色卡，它会打开导入报告，把导入时注意到的问题列出来——这份报告别跳过，卡里字段丢失、正则不兼容通常都写在这里。

从链接导入：粘贴角色卡站点的角色页地址，或者卡文件直链。

几个容易忽略的：

  • 聊天记录要 SillyTavern 的 .jsonl，可以一次选几个；
  • ST 主题不在导入里，在 酒馆设置 › 显示 › 导入 ST 主题；
  • 角色页的 配置 页签里能回看这张卡的导入报告，随时复查。

从 DeepSeek 把长对话接回来

这个功能挺特别：在 DeepSeek 官方 App 里聊不下去的长对话，可以搬到酒馆接着聊。

  1. 先在 DeepSeek 的设置里导出全部历史对话，得到一个 ZIP；
  2. 二选一：文件管理器里把 ZIP 分享给 dsh-Go，或者 酒馆 › 导入 › 从 DeepSeek 接回来 再选这个文件。

接回后的行为要提前知道：

  • 列表按聊得多少排序，最长的那段已经勾好，点底部按钮就直接打开、发下一句；
  • 每段对话会变成书架上的一个角色，原来「重新生成/修改」留下的分支都在；
  • 被撤回或没写完的回复会保留，但不会再发给模型；
  • 重复导入同一段不会重复，点它直接打开；
  • 接回的对话用更大的上下文（至少 64K）和更长的回复上限；
  • 超出上下文的早期内容模型看不到，所以最开头两条（不算撤回/没写完的）会被塞进角色描述，每条最多 4000 字。

这里就是费用提醒：接回一段很长的对话，每回合都在为 64K 上下文付费。

四、书架、角色页、群聊

书架顶部是最近聊过的对话，点 继续 接着上次；下面是角色网格，角色多了能搜索、按标签筛选、切排序。

点卡进角色页，三个页签：

页签 里面有什么
对话 左右滑选开场白，点 开始 或 继续上次
设定 卡面与角色设定
配置 这张卡的世界书、Live2D 形象、导入报告

编辑角色只改能改的字段——卡里改不了的内容，保存时原样保留，而且已有对话不会变（不会因为改了卡把历史重写一遍）。

对话一栏列出全部聊天，最新在上，长按可删。顶部 新建群聊 要书架上至少两个角色才可点。

群聊的规矩：在 谁在里面 按点选顺序排，第一个是主持；故事共用的状态、导演和秘密都记在主持的卡上；主持可以不在发言名单里。进群后能看到谁在说，也能 让大家接着说；发言名单和顺序在 群聊设置 里改。

五、开始对话：输入条上那几个键

对话页上面是舞台（故事与消息），下面是输入条。除了正常打字：

  • 长按发送键：选 以旁白身份发（自己当旁白推进剧情）或 只发，不回复（只落一条消息，不催模型）；
  • 帮我写：让模型替你写这一句；
  • 接着写：让最后一条继续往下；
  • 输入条上方还有 快速回复 和 掷骰——选好骰子，结果先放进输入框，你确认后再发送（不会直接替你摇完就发）。

六、换回答、分支、消息菜单

这部分是酒馆真正的骨架。

任何一条角色回复都能左右滑，在「上一个回答 / 下一个回答」之间切；最后一条向左滑到头 = 重新生成。滑到别的备选时，顶部会提示「切到了另一条分支」，可以撤销。

长按消息出菜单：复制、编辑、从这里分叉、重新生成、接着写、加书签、对模型隐藏、只删这一条、删除这条及以后、看看发了什么。

两个菜单项值得单独说：

  • 对模型隐藏：消息还留在你眼前，但不进上下文——这是在不破坏阅读连续性的前提下省 token 的主要手段；
  • 看看发了什么：直接把这一回合实际发给模型的内容摊开，排查「它为什么忘了设定/为什么不按格式回答」时，先看这里，比猜快得多。

分支页把整段对话的岔路画成一棵树：缩进的行是从上一行末尾岔出的另一条路；点一行可以切过去、给它起名；没在走的那条也能删。

七、舞台四栏：本局 / 状态 / 导演 / 本回合

对话页右上角 舞台 打开侧栏：

本局

这段对话正在用的模型、思考、人设、预设、世界书、排版、背景图；以及 书签、分支、在对话里搜索、导出聊天记录、导出成故事书（EPUB / TXT / 长图）。

状态

卡定义的状态，显示到当前这条消息为止。这回合变了的会标 「+5」 这样的记号；点一项能看全部或直接改，改动记在这条消息上——所以换回答、切分支时会跟着回退，不会出现「状态和剧情对不上」。没定义状态的老卡，这里会列出它的变量。

导演

打开 自动导演 后，它每隔几回合在后台读一遍剧情，记下 导演笔记（默认藏着怕剧透），再给你几条建议回复；也能手动 让导演想一想。后台记录 里能看到每次状态改动和导演运行，最新的在上，最多 100 条。

本回合

这一回合实际发出去的内容，完整检视——和长按菜单里的「看看发了什么」是同一类信息，区别在于这里是按回合组织的。

八、排版：气泡 / 小说 / 视觉小说

每段对话可以在 舞台 › 本局 单独换排版，全局在 酒馆设置 › 显示：

排版 适合
气泡 常规对话，谁说什么一眼分清
小说 长段叙述、沉浸阅读，界面上少一层壳
视觉小说 有大背景图、想看画面信息的时候

同一组里还有 正文字号、配色、是否 用卡自带的样式、导入 ST 主题，以及 HTML 面板 和 整页画布 的开关。

  • 用卡自带的样式：卡里带了 CSS 就生效，观感更接近作者想要的样子，但也可能和你的配色打架，看着别扭就关掉；
  • HTML 面板 / 整页画布：卡里的富交互（状态面板、小游戏）要靠它们渲染，不需要就关掉，省性能也少一层风险。

九、安全：两个默认关着的开关

酒馆设置 › 安全

  • 网页里不运行卡的脚本
  • 网页不联网

默认都关闭，也就是默认允许卡的脚本运行、允许页面联网。这在追完卡作者的炫技效果时很爽，但代价是：卡来自第三方，脚本和网络请求都不受你控制。

建议的用法：平时开着这两项，只在你信任的卡、并且确实需要那个效果时，临时关掉试一次。酒馆本身也明确说了——它不审查卡和模型的内容。

十、备份、导出与用量

数据在哪

角色卡、对话、世界书、预设、人设、设置、Live2D 形象，全在这台手机上。

备份与恢复

酒馆设置 › 数据：

  • 备份整个酒馆 —— 打成一个 zip；
  • 从备份恢复；
  • 存储占用 —— 按角色、对话、预设等分项统计，突然变大会看到是对话涨了还是资源涨了；
  • 用量统计 —— 每段对话用了多少 token，包括缓存命中。

换手机、重置、卸载前先备份。 这一条是硬提醒：删除角色会连它的对话一起删，删前会确认，但不能撤销。

导出

舞台 › 本局 里：

  • 导出聊天记录；
  • 导出成故事书 —— EPUB、纯文本 TXT、或 长图。

长图适合发给人看，EPUB 适合自己留着读，TXT 适合再加工。

十一、资源库：把设定和格式攒起来

酒馆 › 资源库

里面是 世界书、预设、正则、默认人设、快速回复。

  • 世界书、预设、正则都能从文件导入，也能编辑；
  • 命中测试：世界书看哪些条目会被命中，正则看替换前后——导入别人写的正则后先跑一次，比在对话里出问题再回头查省事得多；
  • 世界书设为全局后对所有对话生效；卡自带的世界书跟着卡走；
  • 默认人设是你在对话里扮演的人，长按可以设默认或删除。

十二、按水平分层的用法

层级 会做什么
入门 进酒馆、填 Key、导一张卡、选开场白开始聊
熟练 左右滑换回答、用「对模型隐藏」省 token、会看「看看发了什么」定位设定丢失、按对话换排版、定期备份
精通 用世界书 + 预设 + 正则把「人设/格式/触发」拆开管理并做命中测试；用分支树管理剧情岔路；用状态 + 自动导演维持长线的连贯；群聊里安排主持与发言顺序；用 DeepSeek 接回迁移老对话；靠用量统计（含缓存命中）和上下文控制把每回合成本压住

几条实操经验：

  1. 先备份再折腾——改预设、导卡、接回长对话之前，打个整库 zip；
  2. 卡里的脚本默认别放行，需要时再开，用完关回去；
  3. 长对话要主动瘦身：对早期消息用「对模型隐藏」，或另起一段、把关键设定留在世界书里；
  4. 回了奇怪的格式，先看 本回合 的完整输入，再决定是改正则还是改预设；
  5. 状态和剧情对不上，去 舞台 › 状态 看看是不是切了分支没跟上——它是跟着消息走的。
